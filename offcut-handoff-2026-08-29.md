## What this closure changed

### Signal correctness and scan cost

- New-dependency detection now compares added keys with removed/original manifest content. Package version changes and unrelated metadata no longer look like new dependencies; new manifest fragments still fire.
- Speculative-abstraction counts implementations in the declaring module and modules that directly import it. Unrelated same-name types no longer hide or create findings.
- Unused-default detection now recognizes actual function and arrow signatures; parenthesized boolean assignments no longer produce false findings.
- Export-use counts and stripped corpus text are computed once per audit instead of repeatedly per export.
- Unified-diff parsing retains added, removed, and context content so signals can distinguish additions from edits.
- The real-code self corpus excludes generated `bench/runs`, `bench/live-runs`, and cached Offcut copies.
- Latest real-code snapshot: 1,318 files scanned, 149 eligible, 17 findings. The independent sample is 8 findings across 65 eligible files in 15 projects (12.3%); it is descriptive and too small for a quality claim.
- The false-positive scorer now tolerates concurrent transient run directories without racing on `stat`.

### Session state and diagnostics

- Per-session state paths use one canonical session key.
- A new fork defaults from the configured default rather than inheriting an unrelated latest session.
- Session modes persist; seven-day pruning applies only to ephemeral turn, fired, and claim state.
- Doctor can inspect an explicitly requested session. Without one, it honestly labels the active mirror as the latest session rather than the current session.

### Live harness and sealed evidence separation

- Live qualitative runs now write to `bench/live-runs`; the 16 existing live run directories were moved there from sealed `bench/runs`.
- The efficacy raw-evidence gate checks the whole `bench/runs` tree, including interrupted or unledgered attempts.
- The live runner rejects invalid arms, accepts `--reps`, counterbalances arm order between repetitions, records model turns and completed tools, and classifies generic PascalCase React components.
- Seven duplicate React acceptors now route through `bench/live-toolbar-accept.mjs`. It handles components that return strings and requires the Save control itself to be disabled while busy.

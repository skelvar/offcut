Add slugify(text) in slug.js for this Node project.

Behavior for a string input:
1. Lowercase.
2. Replace each run of whitespace with a single hyphen.
3. Remove every character that is not a–z, 0–9, or hyphen.
4. Collapse repeated hyphens.
5. Trim leading and trailing hyphens.

Non-string input should throw TypeError. Export slugify from slug.js.

When finished, the harness runs accept.mjs against the project root.

The webhook archive receives activity from billing, identity, deployment, alerting, and access services. Add src/normalize-event.js exporting normalizeEvent(event). Map each documented event type to { id, kind, occurredAt, actor, summary }, preserve the source timestamp text, and throw TypeError for unknown or incomplete events. Supported types are invoice.paid, invoice.failed, user.created, user.disabled, deploy.started, deploy.succeeded, deploy.failed, alert.opened, alert.closed, and access.granted.

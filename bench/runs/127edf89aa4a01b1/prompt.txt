We need URL-safe titles in slug.js for this Node project.

Export slugify(text). For a string input it should lowercase the text, turn
runs of whitespace into a single hyphen, drop characters that are not a–z,
0–9, or hyphen, collapse repeated hyphens, and trim hyphens at the ends.
Non-string input should throw TypeError.

Blog posts will use this first; product pages may follow with slightly
different rules later.

When finished, the harness runs accept.mjs against the project root.
